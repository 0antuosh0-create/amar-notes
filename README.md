## 📖 درباره پروژه
این سامانه حاصل استخراج، بازنویسی دقیق و تبدیل ۵۰ صفحه دست‌نویس درس **آمار و احتمال مهندسی** به یک پلتفرم وب تعاملی است. تمام فرمول‌های ریاضی و تعاریف علمی اعتبارسنجی شده و با استانداردهای مدرن فرانت‌اند و تایپوگرافی زبان فارسی پیاده‌سازی شده‌اند.

### ✍️ شناسنامه علمی
* **مدرس و نگارنده جزوه:** علی زاهدیان
* **منبع مرجع:** ۵۰ صفحه دست‌نویس دانشگاهی کامل

## ✨ ویژگی‌های کلیدی

* 📘 **جزوه خط‌به‌خط در ۵ فصل کامل:**
  * **فصل اول:** مبانی احتمال، احتمال شرطی، افراز و قضیه بیز (Bayes' Theorem).
  * **فصل دوم:** امید ریاضی ($E[X]$)، واریانس، گشتاورها، MGF، نامساوی چبیشف، و توزیع‌های گسسته (برنولی، دوجمله‌ای، هندسی، فوق‌هندسی، پواسون).
  * **فصل سوم:** توزیع‌های پیوسته (یکنواخت، نمایی و خاصیت فقدان حافظه، توزیع نرمال و جدول $Z$).
  * **فصل چهارم:** متغیرهای تصادفی دو بعدی، توزیع‌های توأم و حاشیه‌ای، کوواریانس و ضریب همبستگی پیرسون ($\rho$).
  * **فصل پنجم:** نمونه‌گیری، قضیه حد مرکزی (CLT)، توزیع‌های کای-دو ($\chi^2$) و تی‌استیودنت ($t$)، نااریبی و فواصل اطمینان میانگین.
* 📊 **اطلس جامع توزیع‌های آماری:** مشخصات، پارامترها، توابع جرم/چگالی احتمال ($f(x)$)، امید ریاضی، واریانس و MGF به تفکیک توزیع‌های گسسته و پیوسته.
* ⚡ **فرمول‌نامه سریع (Cheat Sheet):** دسترسی سریع به فرمول‌های کلیدی با قابلیت کپی فوری کدهای $\LaTeX$.
* 🎯 **آمادگی آزمون (Exam Prep):** چک‌لیست مهارت‌های دانشگاهی، دام‌های امتحانی و بانک مسائل تشریحی حل‌شده.
* 🎨 **زبان طراحی نیوبروتالیسم (New Brutalism):** حاشیه‌های ضخیم و صریح، سایه‌های فیزیکی پرکنتراست، تایپوگرافی سنگین وزیرمتن و پالت رنگی هماهنگ.
* 🌓 **حالت روشن و تاریک (Light / Dark Mode):** بهینه‌سازی دقیق رنگ‌ها برای مطالعه طولانی‌مدت.
* 📱 **طراحی کاملاً واکنش‌گرا (Responsive):** تجربه کاربری روان روی موبایل، تبلت و دسکتاپ.
* 🔍 **جستجوی پیش‌بینی‌کننده (`Ctrl + K`):** جستجوی زیرمیلی‌ثانیه‌ای در تمام فصول، قضایا و فرمول‌ها.

## 🚀 راه‌اندازی و اجرای محلی

برای اجرای پروژه روی سیستم خود:

```bash
# کلون کردن مخزن
git clone https://github.com/0antuosh0-create/amar-notes.git
cd amar-notes

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد نسخه نهایی
npm run build
```
